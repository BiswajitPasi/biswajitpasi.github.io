01 / 05 — COMPUTER VISION

AI People Occupancy & Pose Detection

Multi-camera system that counts people and classifies posture — standing, sitting, lying — in real time.

  • YOLOv8-Pose on ONNX Runtime, called in-process from .NET — no separate Python service
  • Inference in a background service; the dashboard only serves finished frames, so the live view never lags
  • Posture by priority chain: knee angle → leg extension → box aspect ratio
  • 95%+ accuracy in production, on ordinary hardware, fully on-premises

  • Fully bilingual English / Arabic

Vehicle Entry with Plate Recognition

Cars are recognised at the gate, verified, and let through — with a personalised welcome on screen.

04 / 05 — DOCUMENT AI

Self-Hosted GCC ID Extraction

Structured data from Iqama, Emirates ID, Oman civil cards and passports — without a single cloud API call.

  • Tiered pipeline: machine-readable zone first, vision-language model only when needed
  • Qwen2.5-VL served locally through Ollama — documents never leave the network
  • Arabic / English field separation and Hijri date normalisation
  • Designed around PDPL data-residency requirements
